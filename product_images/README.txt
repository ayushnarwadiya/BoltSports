PRODUCT IMAGES FOLDER
=====================
Put one photo per product in this folder and name it exactly like the product's slug
(the first column below). Use .jpg, .jpeg, .png or .webp.

Then run:   python manage.py attach_product_images

Tips:
- Use a clear photo of the product on a plain background, landscape or square, about 800 x 600 pixels.
- Use free-to-use photos (for example from Unsplash, Pexels or Pixabay) or photos you take yourself.
- To replace an image that is already set, add --overwrite to the command.
- You can also upload or change any image from the admin panel (Store > Products).
